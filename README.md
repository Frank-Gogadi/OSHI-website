# OSHI-website# Organization for Strategic Health Interventions (OSHI)

## 🌍 OSHI Official Website

This repository contains the website of **Organization for Strategic Health Interventions (OSHI)**, a local non-governmental organization working to build healthier, resilient, and empowered communities in Tanzania.

## About OSHI

Organization for Strategic Health Interventions (OSHI) is a local NGO established under the **Non-Governmental Organizations Act No. 24 of 2002**, with registration number **ooNGO/R/1179**.

OSHI works with government institutions, development partners, communities, and other stakeholders to improve health and contribute to sustainable community development.

## 🚀 GitHub Pages

The website can be hosted using **GitHub Pages**.

After enabling GitHub Pages, the website will be available at:

```text
https://YOUR-USERNAME.github.io/REPOSITORY-NAME/
```

Replace:

* `YOUR-USERNAME` with your GitHub username
* `REPOSITORY-NAME` with your GitHub repository name

## 💻 Local Development

To work on the website locally:

1. Download or clone the repository.
2. Open the project in Visual Studio Code.
3. Open `index.html` in a browser.
4. For easier development, use the Live Server extension in Visual Studio Code.

## 🔗 Website Assets

The website uses local CSS, JavaScript, and image files.

Example image path:

```html
<img src="image/oshilogo.png" alt="OSHI Logo">
```

Example CSS path:

```html
<link rel="stylesheet" href="assets/css/style.css">
```

Example JavaScript path:

```html
<script src="assets/js/main.js"></script>
```

When uploading the project to GitHub, keep the existing folder structure so that website links, images, CSS, and JavaScript continue to work correctly.
